# 💍 دعوة الزفاف الرقمية — سارة و أحمد

دعوة زفاف تفاعلية بتصميم "ذهبي كلاسيك"، مبنية بـ **HTML / CSS / JavaScript** بسيط بدون أي إطار عمل (Framework)، عشان تكون سهلة التعديل، سريعة التحميل، وسهلة الرفع على GitHub Pages مجانًا.

> ⚠️ **ملاحظة مهمة بخصوص المحتوى:** التصميم والكود هنا أصلي بالكامل، اتعمل خصيصًا ليك، ومش نسخة من أي منتج تجاري تاني. الأسماء والتواريخ والصور اللي جوه المشروع placeholder (بيانات تجريبية) لازم تستبدلها ببياناتك الحقيقية زي ما هو موضح تحت.

## ✨ المميزات

- شاشة دخول بـ "ختم" ذهبي متحرك، بيفتح الدعوة عند الضغط عليه
- تصميم عربي RTL بالكامل مع خطوط Google Fonts عربية أنيقة (Aref Ruqaa / Amiri / Tajawal)
- عدّاد تنازلي حي لموعد الفرح
- برنامج حفل (Timeline) قابل للتعديل بالكامل
- معرض صور مع عارض مكبّر (Lightbox)، وبديل ذهبي أنيق لو الصور لسه متضافتش
- خريطة Google Maps مدمجة تلقائيًا من اسم المكان
- زر "حفظ التاريخ" بيولّد رابط Google Calendar تلقائيًا
- نموذج تأكيد حضور (RSVP) ودفتر تهاني، شغالين فورًا (وضع تجريبي محلي)، مع دعم اختياري للربط بـ [Formspree](https://formspree.io) لاستقبال الردود بالإيميل فعليًا
- أنيميشن ظهور تدريجي عند التمرير، ومحترم لإعداد "تقليل الحركة" في المتصفح
- **ملف إعدادات واحد فقط (`config.js`)** بيتحكم في كل بيانات الموقع — من غير ما تلمس HTML أو CSS

## 🛠️ التخصيص (خطوة واحدة تقريبًا)

كل بيانات الدعوة موجودة في ملف واحد:

```
assets/js/config.js
```

افتحه بأي محرر نصوص (VS Code، Notepad++، أو حتى Notepad عادي) وعدّل:

| العنصر | المكان في `config.js` |
|---|---|
| أسماء العروسين | `couple.bride` / `couple.groom` |
| الآية القرآنية | `ayah.text` / `ayah.reference` |
| نص الدعوة | `inviteText` |
| تاريخ ووقت الحفل | `event.dateISO` (صيغة `YYYY-MM-DDTHH:mm:ss`) و `event.dateDisplay` |
| برنامج الحفل | مصفوفة `timeline` — أضف/احذف عناصر بحرية |
| معرض الصور | مصفوفة `gallery` |
| مكان الحفل | `location.name` و `location.mapQuery` |
| موعد الرد على الدعوة | `rsvp.deadlineDisplay` |
| أرقام وروابط التواصل | `contact.whatsapp` / `contact.phone` / `contact.email` |

### إضافة صور المعرض

1. جهّز 4 صور (أو أكتر) بصيغة `.jpg` أو `.webp`
2. ضعها داخل `assets/images/gallery/`
3. سمّيها زي المسارات المكتوبة في `config.js` (أو غيّر المسارات في `config.js` لتطابق أسماء صورك)

لو مفيش صور لسه، الموقع هيعرض إطار ذهبي بديل تلقائيًا بدل ما يبوّظ الشكل.

### تفعيل استقبال الردود فعليًا (اختياري لكن منصوح بيه)

بدون أي إعداد، الردود (RSVP + دفتر التهاني) بتتخزن في متصفح كل زائر بس (`localStorage`) — يعني مش بتوصلك. عشان تستقبلها فعليًا بالإيميل مجانًا:

1. اعمل حساب مجاني على [formspree.io](https://formspree.io)
2. اعمل "New Form" وهيديك رابط زي: `https://formspree.io/f/xxxxxxx`
3. الصقه في `config.js`:
   ```js
   rsvp: { formspreeEndpoint: "https://formspree.io/f/xxxxxxx" }
   guestbook: { formspreeEndpoint: "https://formspree.io/f/yyyyyyy" }
   ```
4. خلاص، أي رد هيوصلك على إيميلك مباشرة.

## 💻 التجربة محليًا قبل الرفع

مفيش داعي لأي تثبيت. افتح ملف `index.html` بأي متصفح (دبل كليك عليه) وهتشوف الموقع شغال على طول.

لتجربة أقرب للواقع (مهم عشان الخريطة تشتغل صح)، تقدر تشغّل سيرفر محلي بسيط:

```bash
# لو عندك Python مثبت
python3 -m http.server 8000
# افتح المتصفح على: http://localhost:8000
```

## 🚀 الرفع على GitHub خطوة بخطوة

### 1) إنشاء المستودع (Repository)

1. سجّل دخول على [github.com](https://github.com)
2. اضغط على **+** فوق يمين الصفحة ← **New repository**
3. اكتب اسم زي `wedding-invitation`
4. سيبه **Public**، **من غير** ما تضيف README (عندنا واحد جاهز)
5. اضغط **Create repository**

### 2) رفع الملفات — طريقتان

**الطريقة الأسهل (بدون Git، من المتصفح مباشرة):**

1. فك ضغط ملف الـ ZIP اللي معاك على جهازك
2. في صفحة المستودع الجديد على GitHub، اضغط **uploading an existing file**
3. اسحب كل الملفات والمجلدات (`index.html`, `assets`, `README.md`, ...) وأفلتها في الصفحة
4. اكتب رسالة زي `رفع الموقع` واضغط **Commit changes**

**الطريقة الاحترافية (باستخدام Git من الطرفية/Terminal):**

```bash
# 1) فك ضغط الملف وادخل المجلد
cd wedding-invitation

# 2) هيّئ مستودع Git محلي
git init
git add .
git commit -m "الإصدار الأول من دعوة الزفاف"

# 3) اربطه بالمستودع على GitHub (غيّر USERNAME باسمك)
git branch -M main
git remote add origin https://github.com/USERNAME/wedding-invitation.git
git push -u origin main
```

### 3) نشر الموقع مجانًا عبر GitHub Pages

1. في صفحة المستودع، روح لـ **Settings**
2. من القائمة الجانبية، اختار **Pages**
3. تحت **Build and deployment** ← **Source**، اختار **Deploy from a branch**
4. اختار البرانش **main** والمجلد **/ (root)**، ثم **Save**
5. استنى دقيقة أو اتنين، هيظهرلك رابط زي:
   ```
   https://USERNAME.github.io/wedding-invitation/
   ```
6. ده رابط دعوتك جاهز تبعته لضيوفك 🤍

> بعد كل تعديل في `config.js` أو أي ملف، لازم تعمل `git add . && git commit -m "..." && git push` تاني عشان التغيير يظهر على الرابط المباشر (أو ترفع الملفات المعدّلة يدويًا لو مستخدم طريقة السحب والإفلات).

## 🔒 الخصوصية

الردود المحفوظة بوضع `localStorage` (التجريبي) موجودة فقط في متصفح كل زائر ومش بتتشارك مع حد، حتى معاك. عشان تستقبل الردود فعليًا، لازم تفعّل Formspree زي ما هو موضّح فوق، أو تستبدلها بأي خدمة backend تانية تفضّلها.
